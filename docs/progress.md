## 运行方式

云会话网络屏蔽 FRED、联储官网和 HuggingFace，因此计算全部在 GitHub Actions 上进行（公开仓库，不计费）：

| 工作流 | 触发 | 内容 | 耗时 |
| --- | --- | --- | --- |
| `liquidity.yml` | 推送 `liquidity/`（文本模块除外）或手动 | 下载 FRED 数据、计算指数、提交 `data/raw/` 与 `output/` | 约1分钟 |
| `text.yml` | 推送 `liquidity/text/` 或手动 | 抓取联储文本、打分、重算指数、提交 `data/text/` 与 `output/` | 词典法约15分钟；首次模型打分约数小时 |
