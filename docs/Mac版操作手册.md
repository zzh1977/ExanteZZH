# 本地 AI 文件整理 · Mac 版操作手册

适用：Apple 芯片的 Mac（本手册按 M2 Pro / M2 Max、32GB 内存、1TB 内置硬盘编写）。
安装时联网一次；装好后整理文件时可以完全断网。模型放在内置硬盘，外接硬盘只放待整理的材料和整理结果。

> 32GB 内存的 M2 是 M2 Pro 或 M2 Max（标准版 M2 最多 24GB）。它们自带显卡加速，跑本地模型比 Windows 纯 CPU 快好几倍，所以 Mac 版默认用更大、更准的模型。

## 总流程

| 阶段 | 做什么 | 预计时间 |
|---|---|---|
| 第一部分 | 安装 Ollama、Python 和整理工具，下载模型（需联网） | 约 30–60 分钟（主要是下载约 14GB） |
| 第二部分 | 准备外接硬盘、授权终端访问 | 约 10 分钟 |
| 第三部分 | 用 50–100 个文件试点 | 约 30 分钟 |
| 第四部分 | 正式整理（可断网） | 视文件数量 |
| 第五部分 | 以后有新文件时 | 同上 |

> 本手册的命令都在 **终端** 里输入。打开方法：按 `Cmd + 空格`，输入“终端”，回车。
> 路径里有空格或中文时，最省事的办法是：先输入命令的前半部分，再把文件夹从“访达”**拖进终端窗口**，路径会自动填好。

<a id="sec-2"></a>
## Mac 版的分工和存放位置

<a id="sec-3"></a>
### 模型分工（32GB 内存的默认配置）

| 文件 | 处理方式 | 模型 | 大小 |
|---|---|---|---|
| 中文文档 | 只单独分出来，不读内容、不改名 | 默认不用（可选 `qwen3:8b` 细分） | （5.2GB） |
| 英文 / 德文文档 | 读内容分类、起名、写中文摘要 | **`gemma3:12b`** | 约 8.1GB |
| 照片 | 看画面分类、按拍摄日期命名 | **`qwen3-vl:8b`** | 约 6.1GB |
| 音视频、安装包、压缩包、代码 | 按扩展名归类 | 不用 | — |

和 Windows 版（16GB）相比，英德文从 `llama3.1:8b` 换成多语言更强的 `gemma3:12b`，照片从 `qwen3-vl:4b` 换成更准的 `qwen3-vl:8b`。两个模型同时装进内存也只占约 15GB，32GB 绰绰有余。

速度估计（M2 Pro，以实际为准）：英德文文档每个约 8–20 秒，照片每张约 5–15 秒，中文文档和其他文件不到 1 秒。

<a id="sec-4"></a>
### 什么放在哪里

| 位置 | 内容 | 大小 |
|---|---|---|
| 内置硬盘 `~/.ollama/models` | 模型文件（Ollama 默认位置，不用改设置） | 约 14GB（加中文细分约 19GB） |
| 内置硬盘 `~/AI/` | 整理工具、Python 环境、计划表和撤销日志、文档 | 不到 1GB |
| 外接硬盘 `/Volumes/资料盘/待整理` | 待整理的材料 | — |
| 外接硬盘 `/Volumes/资料盘/已整理` | 整理结果，含归档汇总表 `_归档索引` | — |

（`~` 表示你的用户文件夹，即 `/Users/你的用户名`。“资料盘”换成你外接硬盘的实际名字。）

为什么这样放：
- **模型放内置硬盘**：加载最快（约 1–2 秒）；外接硬盘拔掉也不影响模型。
- **计划表和撤销日志放内置硬盘**：外接硬盘万一断开，撤销记录也不会丢。
- **材料和结果放同一块外接硬盘**：整理时的“移动”只是改名，瞬间完成，不额外占空间。

## 第一部分：安装（需联网，只做一次）

<a id="sec-7"></a>
### 步骤 1：下载整理工具

1. 打开本仓库的 GitHub 页面，左上角分支选择框选 `claude/local-ai-model-setup-a09mzp`（如果已合并到 `main`，就选 `main`）。
2. 点绿色的 **Code** 按钮 → **Download ZIP**。
3. Safari 会自动解压到“下载”文件夹。把解压出来的文件夹改名为 `ExanteZZH`，即 `~/Downloads/ExanteZZH`。
4. 确认里面有 `file_organizer`、`scripts`、`docs` 等文件夹。

<a id="sec-8"></a>
### 步骤 2：安装 Ollama

1. 打开 <https://ollama.com/download>，选 **macOS**，下载安装包。
2. 双击打开下载的文件，把 Ollama 拖进“应用程序”文件夹。
3. 在“应用程序”里打开 Ollama。第一次打开时如果询问是否安装命令行工具，点 **安装** 并输入开机密码。
4. 屏幕顶部菜单栏出现羊驼图标，说明 Ollama 在运行。
5. 打开终端，输入下面的命令，能显示版本号即可：
   ```bash
   ollama --version
   ```

<a id="sec-9"></a>
### 步骤 3：安装 Python 3.14

1. 打开 <https://www.python.org/downloads/macos/>。
2. 找到 **Python 3.14.x**，下载 **macOS 64-bit universal2 installer**（`.pkg` 文件）。
3. 双击安装，一路“继续”即可。
4. 打开一个**新的**终端窗口，输入：
   ```bash
   python3.14 --version
   ```
   显示 `Python 3.14.x` 即成功。

说明：
- Mac 自带的 `python3` 版本较旧，有时还会弹窗要求安装“命令行开发者工具”，不用管它。安装脚本会自动找到 3.14。
- 系统里的 Python 只用来创建环境，**不往里装任何包**。整理工具需要的包都装在它自己的环境 `~/AI/venv` 里。

<a id="sec-10"></a>
### 步骤 4：运行安装脚本

在终端输入：

```bash
cd ~/Downloads/ExanteZZH
bash scripts/mac/setup_mac.sh
```

想让中文文档也用 Qwen 细分（合同、发票、报告……），改用：

```bash
bash scripts/mac/setup_mac.sh --with-zh
```

脚本会依次：

- `[1/5]` 检查芯片、内存，确认 Ollama 在运行（没运行会自动打开）
- `[2/5]` 下载模型：`gemma3:12b`、`qwen3-vl:8b`（加 `--with-zh` 时还有 `qwen3:8b`），有进度条
- `[3/5]` 把整理工具和文档复制到 `~/AI`
- `[4/5]` 创建工具专用的 Python 环境 `~/AI/venv` 并安装依赖包，最后显示 `Packages OK`
- `[5/5]` 检查设置里用到的模型是否都已下载

看到 `安装完成` 即可。安装脚本可以重复运行：已下载的模型不会重新下载，你改过的 `config.json` 会保留。

<a id="sec-11"></a>
### 步骤 5：验证

逐条输入，检查四项：

1. 模型是否都在：
   ```bash
   ollama list
   ```
   应看到 `gemma3:12b`、`qwen3-vl:8b`（和 `qwen3:8b`）。

2. 英德文模型能否回答：
   ```bash
   ollama run gemma3:12b "Fasse in einem Satz zusammen: Das ist ein Test."
   ```
   得到一句德文回答即可。输入 `/bye` 退出。

3. 照片模型能否看图（先在桌面放一张照片 `test.jpg`）：
   ```bash
   ollama run qwen3-vl:8b "用一句话描述这张照片 ~/Desktop/test.jpg"
   ```
   得到一句中文描述即可。输入 `/bye` 退出。

4. 工具的 Python 环境是否正常：
   ```bash
   ~/AI/venv/bin/python -c "import pypdf, docx, openpyxl, pptx, PIL, pillow_heif; print('依赖正常')"
   ```

四项都通过，安装完成。之后可以断网使用。

<a id="sec-12"></a>
## 第二部分：准备外接硬盘

<a id="sec-13"></a>
### 步骤 6：确认硬盘格式

在“访达”里右键外接硬盘 → **显示简介**，看“格式”：

| 格式 | 是否可用 | 说明 |
|---|---|---|
| APFS | 推荐 | 只给 Mac 用时最稳妥 |
| exFAT | 可以 | Mac 和 Windows 都能读写；意外断开时比 APFS 更容易出错，拔之前一定先推出 |
| Mac OS 扩展（HFS+） | 可以 | 老格式，能用 |
| NTFS | 不行 | Mac 只能读、不能写 |

如果需要改格式：打开“磁盘工具” → 选中硬盘 → **抹掉**。**抹掉会清空硬盘上的所有文件**，只对新硬盘或已备份的硬盘这样做。

<a id="sec-14"></a>
### 步骤 7：建好文件夹

在外接硬盘上建两个文件夹：`待整理`（放材料）和 `已整理`（整理结果会放这里）。

<a id="sec-15"></a>
### 步骤 8：让外接硬盘保持连接

整理过程中硬盘不能断开：

1. 打开 **系统设置**，在 **节能**（台式机）或 **电池 → 选项**（笔记本）里，关闭 **“在可能时使硬盘进入睡眠”**（不同 macOS 版本的位置和说法略有不同）。
2. 整理时不要拔线；拔之前在“访达”里点硬盘旁边的 **推出** 按钮。

可选：在 **系统设置 → Spotlight** 里，把外接硬盘加入不搜索的位置（“搜索隐私”），可以避免大量移动文件后系统建索引占用 CPU。

<a id="sec-16"></a>
### 步骤 9：允许终端访问外接硬盘

第一次用终端读写外接硬盘时，macOS 会弹窗询问“终端想访问可移除宗卷上的文件”，点 **允许**。

如果之前点了“不允许”，或终端提示 `Operation not permitted`：打开 **系统设置 → 隐私与安全性 → 文件与文件夹**，找到 **终端**，打开 **可移除宗卷**。材料放在“文稿”“桌面”“下载”里时，也要在这里打开对应的项。

<a id="sec-17"></a>
## 第三部分：第一次使用——小范围试点

<a id="sec-18"></a>
### 步骤 10：准备试点文件

在外接硬盘上新建 `试点` 文件夹，**复制**（不是移动）50–100 个有代表性的文件进去：中文、英文、德文文档和照片各若干，再放几个视频、压缩包。

<a id="sec-19"></a>
### 步骤 11：扫描

```bash
cd ~/AI/file_organizer
./organize.sh scan "/Volumes/资料盘/试点" --out ~/AI/计划/计划_试点.csv
```

屏幕上会依次看到：

```
第 1 步：分流 80 个文件（不用模型）...
第 2 步：英文德文文档 30 个，模型 gemma3:12b
第 2 步：照片 20 个，模型 qwen3-vl:8b
===== 扫描汇总 =====
目录中文件 80 个，计划表 80 行。
```

- 这一步**不会动任何文件**，只生成计划表。
- 外接硬盘上 macOS 自动生成的 `.DS_Store`、`._文件名` 等隐藏文件会自动跳过。
- 中途想停：按 `Control + C`。以后再运行同一条命令，会跳过已处理的文件接着跑。
- 最后一行 “目录中文件 X 个，计划表 X 行” 两个数应相等。

<a id="sec-20"></a>
### 步骤 12：检查计划表

在“访达”里打开 `~/AI/计划/计划_试点.csv`（按 `Cmd + Shift + G` 输入 `~/AI/计划` 可以直接跳过去），用 **Numbers** 或 **Excel** 打开。

各列含义：

| 列 | 含义 | 能改吗 |
|---|---|---|
| action | `move` = 整理；`skip` = 不动 | 能 |
| source | 原文件位置 | **不要改** |
| language | 中文 / 英文 / 德文 / 照片 / 未知 | 参考 |
| category | 要放进的文件夹，可多级，用 `/` 分隔，如 `英文德文文档/合同协议` | 能 |
| new_name | 新文件名（中文文档保持原名） | 能 |
| summary / tags | 中文摘要、关键词 | 参考 |
| confidence | 把握：高/中/低；“规则”表示按扩展名、字符或关键词确定 | 参考 |
| note | 标“建议人工确认”的要重点看 | 参考 |
| duplicate_of | 内容完全相同的另一个文件，这类默认 `skip` | 参考 |
| sha256 | 文件指纹 | **不要改** |

改完后保存为 CSV：

| 软件 | 保存方法 |
|---|---|
| Numbers | **文件 → 导出为 → CSV**，“文本编码”选 **Unicode (UTF-8)**，覆盖原文件 |
| Excel | **文件 → 另存为**，格式选 **CSV UTF-8（逗号分隔）(.csv)** |

保存后关闭表格软件，再进行下一步。

<a id="sec-21"></a>
### 步骤 13：预览，然后试点执行（复制模式）

```bash
./organize.sh apply ~/AI/计划/计划_试点.csv --target "/Volumes/资料盘/试点_结果" --dry-run
./organize.sh apply ~/AI/计划/计划_试点.csv --target "/Volumes/资料盘/试点_结果" --copy
```

第一条只在屏幕上列出“原位置 -> 新位置”；第二条把文件**复制**到 `试点_结果`，原文件不动。结束时会显示对账：计划表总数 = 已复制 + 跳过 + 失败。

<a id="sec-22"></a>
### 步骤 14：检查结果

1. 在“访达”里打开 `试点_结果`，看文件夹结构：`中文文档`、`英文德文文档/合同协议`、`照片/风景旅行`……
2. 打开 `_归档索引/归档汇总_….xlsx`：汇总页、明细页、未归档页。
3. 核对文件是否完好：
   ```bash
   ./organize.sh verify "/Volumes/资料盘/试点_结果"
   ```

<a id="sec-23"></a>
### 步骤 15：评估并调整

1. 数一下分错了多少个。
2. 某类总是分错，按第六部分调整 `config.json`。
3. 重新试点前，**先删掉 `~/AI/计划/计划_试点.csv` 和 `试点_结果` 文件夹**（否则扫描会跳过已处理过的文件），再从步骤 11 开始。
4. 满意后删除 `试点_结果`（它是复制出来的，原文件没动）。

<a id="sec-24"></a>
## 第四部分：正式整理

<a id="sec-25"></a>
### 步骤 16：备份

整理前用“时间机器”或直接复制，把 `待整理` 备份一份。

<a id="sec-26"></a>
### 步骤 17：断网（可选）并扫描

想确保文件内容不出电脑：点屏幕右上角 **控制中心 → Wi-Fi** 关掉（有网线就拔掉）。模型都在本机，断网不影响整理。

```bash
cd ~/AI/file_organizer
caffeinate -i ./organize.sh scan "/Volumes/资料盘/待整理" --out ~/AI/计划/计划_20261028.csv
```

- 前面的 `caffeinate -i` 让 Mac 在扫描期间不睡眠，扫描结束自动恢复。笔记本请接上电源。
- 中断了就再运行同一条命令，会接着跑。
- 照片很多又只想按拍摄年份分：命令末尾加 `--photo-model none`。

<a id="sec-27"></a>
### 步骤 18：检查计划表

和步骤 12 一样。重点看 note 列“建议人工确认”的行、`未识别语言` 的行（多为扫描件）和重复文件。

<a id="sec-28"></a>
### 步骤 19：预览，然后执行

```bash
./organize.sh apply ~/AI/计划/计划_20261028.csv --target "/Volumes/资料盘/已整理" --dry-run
./organize.sh apply ~/AI/计划/计划_20261028.csv --target "/Volumes/资料盘/已整理"
```

- 材料和结果在同一块硬盘上，移动只是改名，瞬间完成。
- 结果放到另一块硬盘时，会先复制、核对指纹一致后才删原文件，任何一步出错原文件都不动。
- 加 `--copy` 改为复制，原文件完全不动（需要双倍空间）。

<a id="sec-29"></a>
### 步骤 20：核对和收尾

```bash
./organize.sh verify "/Volumes/资料盘/已整理"
```

显示“全部完好”即完成。然后：
- 手动处理 `已整理/未识别语言` 里的文件。
- 重复文件仍在原文件夹，确认无用后自己决定是否删除（工具不会删）。
- 保留 `~/AI/计划/` 里的计划表和 `undo_….csv` 撤销日志。

<a id="sec-30"></a>
### 步骤 21：如需撤销

```bash
./organize.sh undo ~/AI/计划/undo_20261028_103000.csv
```

（文件名以 `~/AI/计划/` 里实际生成的为准。）文件会回到原位置。撤销时外接硬盘要连着。

<a id="sec-31"></a>
## 第五部分：以后有新文件时

```bash
cd ~/AI/file_organizer
./organize.sh scan "/Volumes/资料盘/新文件" --out ~/AI/计划/计划_20261120.csv
#（用 Numbers 或 Excel 检查）
```

## 第六部分：调整设置（config.json）

位置：`~/AI/file_organizer/config.json`。改之前先复制一份备份。

**用什么编辑：** 推荐 VS Code 等代码编辑器。用 Mac 自带的“文本编辑”时要先做两件事，否则会把文件改坏：

1. 菜单 **格式 → 制作纯文本**；
2. 菜单 **编辑 → 替换 → 取消勾选“智能引号”**（否则英文引号 `"` 会被自动换成弯引号，设置文件就读不出来了）。

**格式规则：** 引号必须是英文双引号 `"`；每项之间用英文逗号隔开，每组最后一项后面不加逗号。改错了运行时会提示第几行有误。

**常用修改**（各项含义与 Windows 版手册第六部分相同）：

| 想要 | 改法 |
|---|---|
| 中文文档也细分 | `"zh"` 里的 `"model": ""` 改成 `"model": "qwen3:8b"`（需先 `ollama pull qwen3:8b`）；临时试一次可在扫描命令后加 `--zh-model qwen3:8b` |
| 照片只按年份分 | `"photo"` 里的 `"model"` 改成 `""`；临时可加 `--photo-model none` |
| 英德文想更快 | `"en_de"` 的 `"model"` 改成 `"llama3.1:8b"`（需先 `ollama pull llama3.1:8b`） |
| 照片想更快 | `"photo"` 的 `"model"` 改成 `"qwen3-vl:4b"`（需先下载） |
| 增加类别、关键词规则 | 在 `"categories"`、`"keyword_rules"` 里添加 |

改完用试点文件夹再跑一遍确认效果（记得先删旧的计划表）。

## 第七部分：Python 环境维护

| 位置 | 内容 |
|---|---|
| 系统 Python 3.14 | 只用来创建环境，不装任何包 |
| `~/AI/venv/` | 工具专用环境，所有依赖包都在这里 |
| `~/AI/file_organizer/organize.sh` | 运行入口，自动使用 `~/AI/venv`，不需要“激活”环境 |

**重建环境**（报 `No module named …` 或环境损坏时），需联网：

```bash
bash ~/AI/file_organizer/setup_venv.sh
```

**查看环境里装了什么：**

```bash
~/AI/venv/bin/python -m pip list
```

**升级 Python：** 装好新版 Python 后，重新运行步骤 4 的安装脚本即可，环境会自动用新版本重建，设置保留。

**卸载：**
- 只删工具环境：`rm -rf ~/AI/venv`
- 删除整理工具：删除 `~/AI` 文件夹（整理好的文件在外接硬盘上，不受影响）
- 删除模型：`ollama rm 模型名`，或删除 `~/.ollama/models`
- 卸载 Ollama：退出 Ollama，把“应用程序”里的 Ollama 移到废纸篓

<a id="sec-34"></a>
## 第八部分：常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `ollama: command not found` | 命令行工具没装上 | 打开一次 Ollama 应用，按提示安装命令行工具；然后新开终端窗口 |
| `连不上 Ollama` | Ollama 没运行 | 打开“应用程序”里的 Ollama，看菜单栏是否有羊驼图标 |
| `本机缺少模型：…` | 模型没下载 | `ollama pull 模型名`；或在 config.json 里换成已有模型 |
| `Operation not permitted` | 终端没有访问外接硬盘的权限 | 见步骤 9 |
| `zsh: permission denied: ./organize.sh` | 文件没有执行权限 | 运行 `chmod +x ~/AI/file_organizer/*.sh`，或改用 `bash organize.sh …` |
| `没有找到 Python 3.10 或更新的版本` | 没装 python.org 的 Python | 见步骤 3 |
| 找不到 `/Volumes/资料盘` | 硬盘名字不同或没连接 | 在终端输入 `ls /Volumes` 查看实际名字；或把文件夹拖进终端窗口 |
| 整理中途硬盘断开 | 线松了或硬盘休眠 | 重新连接后运行 `verify` 检查；再执行同一计划表，已整理的会显示“源文件不存在”并跳过 |
| 运行慢、电脑卡 | 内存紧张 | 打开“活动监视器”看内存压力；关掉其他大软件；或换成更小的模型（第六部分） |
| 计划表另存后路径出现 `?` | 保存时没选 UTF-8 | 按步骤 12 的方法保存 |
| config.json 报“格式有误” | 弯引号或逗号问题 | 见第六部分“用什么编辑”；或恢复备份 |
| HEIC 照片打不开 | 依赖包没装好 | 运行步骤 5 第 4 条检查，不正常就重建环境 |
