# 美元流动性指数 模型文档

版本：v0.3（第一步 + 鹰鸽文本打分）　更新：2026-10-28　代码：`liquidity/`

## 1. 概述

**目的**：用周度数据刻画美元流动性的松紧，供宏观与资产配置判断使用。

**输出**：每周五一行，包含各分项原始值、标准化分数（z）、三个子指数和一个合成指数。

**符号约定**：所有分数统一为 **正值 = 偏松，负值 = 偏紧**。

**结构**：

| 子指数 | 含义 | 分项 |
| --- | --- | --- |
| 存量 | 美联储资产负债表提供的流动性 | 准备金/GDP；政策性证券净买入/GDP |
| 预期 | 市场与美联储对未来政策路径的预期 | 已定价降息幅度；鹰鸽文本语气；（待办）议息会议意外 |
| 压力 | 货币市场实际融资松紧 | SOFR−IORB 利差；紧急/常备工具使用量 |
| 合成 | 三个子指数等权平均（至少两个有值） | — |

合成权重目前为等权，属于临时设定，待验证后再定（见第6节）。

全部来自 FRED（圣路易斯联储），免费，无需 API key。

## 3. 方法论

### 3.1 时间对齐与防前视

1. 每个观测值的日期先加上发布滞后，改成“公众可见日”。例如 H.4.1 周三数据周四下午发布，日度利率次日可得，GDP 取季度初 + 120 天（约为预估值发布日）。
2. 按周五分桶：周五那一行只包含当周五之前已公布的数据。周度序列取最后值，日度序列取周均值。
3. 缺失最多向前填充2周，GDP 最多20周。
4. 所有标准化只使用当期及以前的数据。

### 3.2 分项定义

**存量 1：准备金/GDP**

> reserves_gdp = WRESBAL ÷ GDP × 100

只与 2009 年以后的历史比较（扩展窗口 z）。原因：2008 年10月以前准备金接近零（约占 GDP 0.06%），把那段时期纳入基准会让此后任何时点都显得“极度宽松”。实测：用2003年起的历史，最新 z 为 +0.12；用2009年起的历史为 −0.71。

**存量 2：政策性证券净买入/GDP（13周）**

> Δ政策 = Δ持有证券合计 − 储备管理期间的（Δ短债 + ΔMBS）
> policy_13w_gdp = 13周累计 Δ政策 ÷ GDP × 100

“储备管理购买”是指美联储为维持准备金充足而买短债，官方明确说明不代表政策立场变化，不应计为宽松。目前设两段窗口：2019-10-15～2020-03-14，以及 2025-12-12 至今（待对照 FOMC 执行说明核实）。窗口内 MBS 到期资金再投资于短债，所以 MBS 变动也一并剔除。标准化用3年滚动 z，标准差下限 0.1%（约300亿美元），以免资产负债表平稳期的小波动被放大。

**预期 1：已定价降息幅度**

> expected_easing_bp = −(DGS1 − DFF) × 100

1年期收益率低于联邦基金利率表示市场预期降息，取反后正值为偏松。选1年期而非2年期，是因为更贴近“未来12个月”，期限溢价更小。标准化用扩展窗口 z。

**压力 1：SOFR − IORB 利差**

> sofr_iorb_bp = (SOFR − IORB) × 100，取反

SOFR 高于准备金利率，说明回购市场资金紧张、准备金接近“充足”下限。标准化用3年滚动 z，标准差下限 1bp。SOFR 自2018年4月才有数据，此前该分项缺失，压力子指数只由工具使用量构成。

**压力 2：紧急/常备工具使用量**

> facility_gdp = (WLCFLL + SWPT + RPONTSYD) ÷ GDP × 100
> z_facility = −扩展窗口 z( ln(1 + facility_gdp ÷ 0.1) )

工具使用量上升首先是压力信号，不是宽松，所以取负。取对数，是为了让2008年（约占 GDP 10%）不压倒其后各次危机。用扩展窗口而非滚动窗口，是因为3年滚动窗口里若还留着2020年的峰值，2023年的银行挤兑贷款就会显得“正常”。各方案的对比见第5节。

**参考（不计入指数）：净流动性**

> net_liquidity = WALCL − 4周平均 TGA − RRP

市场常用的口径。注意它不等于准备金：差额主要是流通中现金（约2.4万亿美元）。

### 3.3 标准化与合成

| 类型 | 方法 | 用于 |
| --- | --- | --- |
| 水平类 | 扩展窗口 z（至少156周） | 准备金、降息幅度、工具使用量 |
| 变动类 | 3年滚动 z（156周，至少104周） | 政策性买债、SOFR−IORB |
| 截断 | 所有 z 截断在 ±4 | 全部 |

- 子指数 = 其分项 z 的简单平均，缺失分项不计入。
- 合成 = 三个子指数平均，至少两个有值才计算。

### 3.4 与原方案的差异

| 原方案 | 本实现 | 原因 |
| --- | --- | --- |
| 净流动性 ≈ 准备金 | 直接用 WRESBAL；净流动性仅作参考 | 两者相差约2.4万亿美元现金 |
| 紧急工具增加 = 宽松 | 计入压力子指数，增加 = 偏紧 | 用量激增发生在危机中 |
| 净买入 = 宽松 | 剔除储备管理购买 | 官方声明不代表政策立场 |
| 2年期 − 联邦基金利率 | 1年期 − 联邦基金利率 | 期限更匹配，期限溢价更小 |
| 统一3年滚动 z | 水平类用扩展窗口、变动类用滚动窗口 | 滚动窗口会把持续状态读成中性 |
| 无融资价格指标 | 新增 SOFR−IORB | 准备金接近下限时最灵敏 |

## 4. 实现

### 4.1 代码结构

| 文件 | 作用 |
| --- | --- |
| `liquidity/config.py` | 序列清单（单位、发布滞后、合理范围）、储备管理窗口、标准化参数 |
| `liquidity/fred.py` | 下载（fredgraph.csv，有 key 时改用官方 API）、重试、本地缓存 |
| `liquidity/transform.py` | 单位识别、按发布日分周、扩展/滚动 z、时间窗口 |
| `liquidity/indicators.py` | 计算各分项、z 分数、子指数与合成 |
| `liquidity/validate.py` | 与 NFCI 的同期、前瞻、领先/滞后相关 |
| `liquidity/__main__.py` | 命令行入口，输出 CSV 与图 |
| `tests/` | 14个测试：时间对齐、单位识别、无前视、储备管理剔除、压力方向等 |

### 4.2 数据流

```
FRED → data/raw/*.csv（缓存）
     → 单位换算 + 合理性检查
     → 按发布日对齐到周五
     → 计算分项 → z 分数 → 子指数 → 合成
     → output/liquidity_index.csv, validation_nfci.csv, lead_lag_nfci.csv, liquidity_index.png
```

### 4.3 运行方式

```bash
pip install -r requirements.txt
python -m liquidity --out output            # 默认使用缓存，--refresh 重新下载
python -m pytest -q
```

本仓库的云会话网络屏蔽了 FRED，因此由 GitHub Actions（`.github/workflows/liquidity.yml`）运行。代码推送到分支时会自动下载数据、运行测试和计算，并把 `data/raw/` 与 `output/` 提交回分支；也可以在 Actions 页面手动触发。

## 5. 验证

**对标物**：芝加哥联储 NFCI，取反后正值 = 金融状况宽松。相关系数基于重叠的周度数据，自相关很强，只能作描述，不能做显著性检验。

**与 −NFCI 的相关（2008-01～2026-10，983周）**

| 子指数 | 同周 | 未来4周变化 | 未来13周变化 | 2010年起同周 |
| --- | --- | --- | --- | --- |
| 存量 | −0.02 | 0.22 | 0.26 | 0.29 |
| 预期 | 0.11 | −0.03 | −0.03 | 0.19 |
| 压力 | 0.66 | −0.10 | −0.13 | 0.41 |
| 合成 | 0.55 | 0.06 | 0.06 | 0.57 |

**解读**：
- 压力子指数与金融状况同步性最强。
- 存量子指数同期相关接近零，但对未来变化为正：美联储往往在危机中扩表，此后金融状况才转松。
- 领先/滞后检验中，存量与合成的最大相关出现在“指数领先26周”，压力出现在“NFCI 领先26周”，都落在检验范围边界上，需要扩大范围再看（已列入待办）。

**危机时点读数**

| 事件 | 周 | 存量 | 预期 | 压力 | 合成 |
| --- | --- | --- | --- | --- | --- |
| 雷曼倒闭后 | 2008-10-10 | 0.55 | 0.44 | −4.00 | −1.00 |
| 回购市场危机 | 2019-09-20 | −0.82 | 0.39 | −1.99 | −0.80 |
| 疫情冲击 | 2020-03-20 | 1.38 | 0.45 | −2.73 | −0.30 |
| 激进加息 | 2022-10-14 | −0.41 | −1.52 | 0.02 | −0.64 |
| 硅谷银行 | 2023-03-24 | −0.29 | 0.27 | −1.93 | −0.65 |

**压力分项方案比较**（选定方案为“对数 + 扩展窗口”）

| 工具使用量处理 | 2008年起同周相关 | 2010年起 | 2019-09 | 2020-03 | 2023-03 |
| --- | --- | --- | --- | --- | --- |
| 原值 + 3年滚动 | 0.64 | 0.22 | −1.09 | −3.20 | −0.09 |
| 原值 + 扩展 | 0.82 | 0.37 | 0.02 | −0.46 | −0.57 |
| **对数 + 扩展** | 0.66 | **0.41** | **−1.99** | **−2.73** | **−1.93** |

“原值 + 扩展”的0.82主要来自2008年一次危机，2019、2020、2023年几乎没有反应。

## 6. 局限与待办

**已知局限**
- GDP 使用最新修订值，不是当时的实时值，存在轻微前视偏差。
- 1年期国债减联邦基金利率包含期限溢价和短债供给因素，不全是加息/降息预期。
- 储备管理购买窗口依据人工判断，日期待核实。
- 合成权重为等权，未经优化。
- 最新一行可能是不完整的一周，周五前会变化。

**待办**
1. **议息会议超预期（原指标5）**：接入 Jarociński-Karadi 美国数据（GitHub: marekjarocinski/jkshocks_update_fed）的“纯货币政策冲击”列，以剥离信息效应。作者更新滞后期间，用 FOMC 当日2年期国债变动近似，并标注为近似。会议日冲击按半衰期衰减累积，并入预期子指数。
2. **鹰鸽文本打分第二阶段**：地区联储主席讲话、新闻发布会实录、点阵图中位数变动。
3. GDP 改用 ALFRED 实时版本。
4. 领先/滞后检验范围扩大到 ±52 周。
5. 依据验证结果确定权重（例如以预测未来13周 NFCI 变化为目标）。

## 7. 鹰鸽文本打分（预期子指数分项）

代码：`liquidity/text/`　运行：`.github/workflows/text.yml`

### 7.1 语料

| 类型 | 来源 | 日期口径 | 权重 |
| --- | --- | --- | --- |
| FOMC 声明 | 联储官网，从日程页和历年历史页提取链接 | 会议决议日（当日14:00发布） | 4 |
| 会议纪要 | 同上 | 会议结束日 + 21 天（纪要三周后发布） | 2 |
| 主席讲话 | 联储官网理事讲话列表 | 讲话日 | 3 |
| 副主席讲话 | 同上 | 讲话日 | 2 |
| 负责监管的副主席讲话 | 同上 | 讲话日 | 1.5 |
| 其他理事讲话 | 同上 | 讲话日 | 1 |

- 起始年份：2008年。
- 链接按网址规律识别（如 `monetaryYYYYMMDDa.htm`、`fomcminutesYYYYMMDD.htm`、`/newsevents/speech/姓名YYYYMMDDa.htm`），不依赖页面版式；每次运行输出 `data/text/fetch_report.csv`，按年份和类别统计找到与下载成功的数量，便于发现遗漏。
- 讲话人身份从讲话页开头识别（Chair / Vice Chair / Vice Chair for Supervision / Governor），不写死人名，因此主席换人后无需改代码。
- 理事会成员均为 FOMC 票委。地区联储主席的讲话分散在12家地区联储网站，暂未纳入（待办）。

### 7.2 句子处理

1. 去掉导航、页眉页脚等，提取正文。
2. 分句：保护 U.S.、Sept. 等缩写，只保留6～120个词的句子。
3. 相关性过滤：只对涉及通胀、经济活动、就业、利率与政策工具、资产负债表的句子打分（思路同 Shah 等 2023）。这样能去掉礼节性内容，也让模型耗时减少数倍。

### 7.3 两种打分器

**词典法（基准与备用）**：话题词与方向词在6个词以内同时出现即计一次：
- 通胀、经济活动“上升” → 鹰；“下降” → 鸽
- 失业、闲置“上升” → 鸽；“下降” → 鹰
- 另有明确的政策短语，如“raise / lower the target range”、“policy firming”、“rate cuts”、“remain accommodative”

规则透明、运行快，但不处理否定和复杂句式。

**FOMC-RoBERTa（主模型）**：Shah、Paturi、Chava（ACL 2023）在 FOMC 文本上训练的鹰/鸽/中性三分类模型（`gtfintechlab/FOMC-RoBERTa`），在 GitHub Actions 的 CPU 上运行。为防止标签顺序读错而导致符号翻转，运行前会用6个已知鹰/鸽的锚定句做校验，不通过即停止使用模型、退回词典法。
**许可证提示**：据我所知该模型采用 CC BY-NC 4.0（非商业）许可，商业使用前需核实。

### 7.4 从句子到周度序列

- 文档语气：tone = (鸽派句数 − 鹰派句数) ÷ 相关句数，取值 −1～+1，正值偏鸽（偏松）。
- 周度语气：每周五取当日及以前发布的所有文档，按“类型/身份权重 × 时间衰减”加权平均。衰减半衰期 14 天，即两周前的文档权重减半。
- 最近120天内没有任何文档的周留空。
- 选用规则：模型分数覆盖 ≥95% 的文档时使用模型分数，否则使用词典分数（`weekly_tone.csv` 的 source 列会注明）。
- 并入指数：对周度语气做扩展窗口 z 分数（`z_text`），与“已定价降息幅度”等权平均，构成预期子指数。

### 7.5 输出文件（`data/text/`）

| 文件 | 内容 |
| --- | --- |
| doc_scores.csv | 每篇文档的类型、日期、讲话人、身份、权重、相关句数、两种打分器的鹰/鸽句数与语气 |
| weekly_tone.csv | 周度语气（词典、模型、选用值） |
| fetch_report.csv | 按年份与类别统计的抓取情况 |
| latest_sentences.csv | 近60天文档的逐句标签（词典与模型对照），用于人工抽查 |

原始网页缓存在 Actions 的缓存中，不提交到仓库。后续运行只对新文档调用模型。

### 7.6 局限

- 未纳入地区联储主席讲话、新闻发布会实录和点阵图。
- 纪要发布日按“会后21天”推算，个别情况可能差一两天。
- 语气水平与经济周期相关（经济强时措辞自然偏鹰），它反映的是政策沟通方向，不等于意外。
- 词典法不处理否定（如 “inflation is not rising”）。
