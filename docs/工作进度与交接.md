## 二、用户需求（已确认）

| 需求 | 落实方式 |
|---|---|
| 本地运行、整理时完全断网 | Ollama 只连 127.0.0.1；Windows 离线打包安装；Mac 联网装一次后可断网 |
| 两套硬件：Windows 16GB；Mac M2（Pro/Max）32GB、1TB | 两套默认模型、两份手册 |
| 中文文档只单独分出来，不读内容 | 程序按汉字比例分流，不调用模型，原名不动；可选 `qwen3:8b` 细分 |
| 照片单独处理，用一个模型 | Windows `qwen3-vl:4b`，Mac `qwen3-vl:8b` |

| 归类准确、绝不丢文件 | 类别固定（JSON 枚举）、规则优先、人工确认计划表；复制后核对 SHA-256 再删原文件、对账、verify、undo、工具不删任何唯一的文件 |
| 汇总归档 | `_归档索引`：Excel 汇总表（汇总 / 明细 / 未归档）、每次清单、累计总索引 |
| Python 环境干净、好维护（不用 conda） | 依赖只装在独立的 venv；`organize.bat` / `organize.sh` 运行，无需激活 |
| Mac：模型放内置硬盘，外接硬盘只放材料和结果 | 模型在 `~/.ollama/models`；工具和计划表在 `~/AI`；`/Volumes/资料盘/待整理` → `已整理` |

<a id="sec-5"></a>
## 五、关键设计决定

| 决定 | 原因 |
|---|---|
| 模型只给建议，文件操作由程序按规则完成 | 模型会出错，但不能因此丢文件 |
| 判断中文、照片不用模型 | 数字符、看扩展名 100% 稳定，且快 |
| 读不出文字、文件名也看不出语言 → `未识别语言` | 不猜，交给人工 |
| 分批调用模型（先英德文，再中文，再照片） | 16GB 内存一次只装一个模型，减少切换 |
| 同盘移动用改名；跨盘先复制成 `.part`、核对指纹、改名，最后删原文件 | 任何一步失败原文件都还在 |
| 计划表 CSV 用带 BOM 的 UTF-8，读时兼容 GBK | Excel / Numbers 打开不乱码，另存后也能读 |
| Windows 推荐 Python 3.14 的 “Windows installer (64-bit)” | 3.12 已无 Windows 安装包；Install Manager 需联网 |
| `--photo-model none` 而不是空字符串 | PowerShell 5.1 会吞掉空字符串参数 |
| 跳过隐藏文件（`.DS_Store`、`._*`） | macOS 在外接硬盘上自动生成 |
| md 固定锚点 `<a id="sec-N">` | 改标题不断链；GitHub 等通用 |

## 八、维护方法

```bash
# 改代码后：跑测试（用装好依赖的 Python，最好装上 markdown-it-py）
venv/bin/python tests/smoke_test.py

# 改文档后：更新目录，再检查
python tools/md_toc.py docs/*.md README.md
python tools/md_toc.py docs/*.md README.md --check

# 重新生成手册网页（--fragment 用于发布到 claude.ai；去掉则生成可直接打开的完整网页）
python tools/build_html.py docs/操作手册.md docs/Mac版操作手册.md docs/常见疑问.md \
  docs/本地AI文件整理方案.md docs/本地模型选型对比.md README.md \
  -o offline-ai-manual.html --fragment --title "离线 AI 文件整理手册" \
  --labels "Windows 手册,Mac 手册,常见疑问,整理方案,模型选型对比,README" \
  --subtitle "用本地模型把中文、英文/德文文档和照片分流归档，整理时可完全断网。包含 Windows 和 Mac 两版操作手册、常见疑问、整体方案、模型选型对比和 README 全文。" \
  --tags "Windows 16GB · llama3.1:8b / qwen3-vl:4b,Mac M2 32GB · gemma3:12b / qwen3-vl:8b,中文 只分流 / qwen3:8b,整理时可完全断网" \
  --foot "本页由仓库中的 Markdown 文件用 tools/build_html.py 生成，内容一致。模型信息截至 2026 年 10 月，下载前请到 Ollama 官网核对模型名称和大小。"
```

发布到原网页：在 Claude 会话里用 Artifact 工具，以 `url` = 上面的网页地址发布 `offline-ai-manual.html`（先读取一次该网页）。本交接文档不在网页里，是给维护者看的。

## 九、和用户协作的习惯

- 用户用中文交流，常在手机上看，回复要先说结论、简短。
- 要求文档“不能遗漏”：网页由脚本生成并逐行核对。
