# 本地 AI 文件整理 · 操作手册（从下载到使用）

适用：Windows 10/11（64 位）、16GB 内存、整理时完全断网。
文件：中文文档单独分出；英文/德文文档用 `llama3.1:8b` 分类；照片用 `qwen3-vl:4b` 分类。

<a id="sec-1"></a>
## 总流程

| 阶段 | 在哪台电脑 | 做什么 | 预计时间 |
|---|---|---|---|
| 第一部分 | **联网电脑** | 下载软件和模型，打成离线包 | 约 1 小时（主要是下载 14GB） |
| 第二部分 | 断网电脑 | 安装、验证 | 约 30 分钟 |
| 第三部分 | 断网电脑 | 用 50–100 个文件试点 | 约 1 小时 |
| 第四部分 | 断网电脑 | 正式整理 | 视文件数量，可挂机过夜 |
| 第五部分 | 断网电脑 | 以后有新文件时 | 同上 |

> 本手册中的命令都在 **PowerShell** 里输入。整理工具用 `.\organize.bat` 运行，它会自动使用工具专用的 Python 环境，不需要手动“激活”。打开方法：在资源管理器中进入某个文件夹，点一下顶部地址栏，输入 `powershell` 后按回车，就会在该文件夹打开 PowerShell。命令可以复制后在 PowerShell 窗口里**右键**粘贴。

<a id="sec-2"></a>
## 准备清单

| 物品 | 要求 |
|---|---|
| 联网电脑 | Windows 10/11 64 位，可用空间 ≥ 30GB。可以临时借用，准备完即可还 |
| 断网电脑 | Windows 10/11 64 位，16GB 内存；D 盘可用空间 ≥ 30GB（不含要整理的文件）。没有 D 盘的，把手册里的 `D:\` 都换成 `C:\` |
| U 盘或移动硬盘 | ≥ 32GB，建议 USB 3.0。**文件系统必须是 exFAT 或 NTFS**（单个模型文件约 5GB，FAT32 放不下）。查看方法：右键 U 盘 → 属性 → 文件系统 |

<a id="sec-3"></a>
## 第一部分：在联网电脑上准备离线包

<a id="sec-4"></a>
### 步骤 1：下载整理工具

1. 打开本仓库的 GitHub 页面，左上角分支选择框选 `claude/local-ai-model-setup-a09mzp`（如果已合并到 `main`，就选 `main`）。
2. 点绿色的 **Code** 按钮 → **Download ZIP**。
3. 把 ZIP 解压到 `D:\`，并把解压出来的文件夹改名为 `ExanteZZH`。
4. 确认 `D:\ExanteZZH` 里有这三个文件夹：`file_organizer`、`scripts`、`docs`。

<a id="sec-5"></a>
### 步骤 2：下载并安装 Ollama

1. 打开 <https://ollama.com/download>，选 **Windows**，下载 `OllamaSetup.exe`。
2. 双击安装，点 **Install**，等待完成。
3. 装好后屏幕右下角托盘区会出现一个羊驼图标，说明 Ollama 在运行。
4. **保留 `OllamaSetup.exe`**，后面要拷到断网电脑。

<a id="sec-6"></a>
### 步骤 3：下载并安装 Python 3.14

1. 打开 <https://www.python.org/downloads/windows/>。
2. 在 “Stable Releases” 列表里找到 **Python 3.14.x**，点它下面的 **Download Windows installer (64-bit)**，得到 `python-3.14.x-amd64.exe`。
   - 不要选 “Python install manager”：它安装时需要联网，断网电脑用不了。
3. 双击安装：
   - **先勾选最下面的 “Add python.exe to PATH”**（很重要）
   - 点 **Install Now**
   - 最后如果出现 “Disable path length limit”，点一下它（允许很长的文件路径）
   - 点 **Close**
4. 验证：**新开**一个 PowerShell 窗口，输入：
   ```powershell
   python --version
   ```
   显示 `Python 3.14.x` 即成功。
   - 如果弹出了微软应用商店：打开 设置 → 应用 → 高级应用设置 → 应用执行别名，把 `python.exe` 和 `python3.exe` 两项关掉，再新开 PowerShell 重试。
5. **保留 `python-3.14.x-amd64.exe`**，后面要拷到断网电脑。
6. 系统 Python 只用来创建环境，**不往里装任何包**。整理工具需要的包都装在它自己的虚拟环境 `venv` 文件夹里（见步骤 6、12 和第七部分），系统 Python 一直保持干净。

<a id="sec-7"></a>
### 步骤 4：建打包文件夹并放入安装程序

1. 新建文件夹 `D:\offline_ai`。
2. 把 `OllamaSetup.exe` 和 `python-3.14.x-amd64.exe` 复制进去。

<a id="sec-8"></a>
### 步骤 5：运行打包脚本（下载模型）

1. 在资源管理器进入 `D:\ExanteZZH\scripts`，在地址栏输入 `powershell` 回车。
2. 输入（复制粘贴即可）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\prepare_offline.ps1 -Out D:\offline_ai
   ```
3. 脚本会依次：
   - `[1/3]` 下载三个模型：`llama3.1:8b`（英德文，约 4.9GB）、`qwen3-vl:4b`（照片，约 3.3GB）、`qwen3:8b`（中文细分备用，约 5.2GB），有进度条
   - `[2/3]` 复制模型文件到 `D:\offline_ai\ollama_models`
   - `[3/3]` 下载 Python 依赖包到 `D:\offline_ai\wheels`
   - 复制整理工具和文档
4. 看到 `Done.` 即完成。

> 中文只分流、不需要细分的话，可以不下 `qwen3:8b`，省 5GB：
> `powershell -ExecutionPolicy Bypass -File .\prepare_offline.ps1 -Out D:\offline_ai -Models llama3.1:8b,qwen3-vl:4b`

出错时：

| 提示 | 处理 |
|---|---|
| `ollama 不是内部或外部命令` | 装完 Ollama 后要**新开** PowerShell 窗口再运行 |
| `Failed to pull model` | 检查网络；模型名是否拼对 |
| `pip download failed` | 检查网络；确认 `python --version` 能用 |

<a id="sec-9"></a>
### 步骤 6（强烈建议）：先在联网电脑上试跑一次

在还能上网的时候确认整套工具能用，到了断网电脑上就不容易卡住。

1. 创建工具专用的 Python 环境（会建在 `D:\ExanteZZH\venv`，联网下载依赖包，不碰系统 Python）：
   ```powershell
   cd D:\ExanteZZH\file_organizer
   .\setup_venv.bat
   ```
   最后看到 `Packages OK` 和 `Done.` 即成功。
2. 新建 `D:\试跑`，随便复制 5–10 个文件进去（中文、英文/德文文档和照片都放几个）。
3. 运行（`organize.bat` 会自动使用上一步建好的环境）：
   ```powershell
   .\organize.bat scan "D:\试跑" --out D:\试跑计划.csv
   ```
4. 能看到 “第 1 步：分流” 和 “第 2 步：…模型 llama3.1:8b / qwen3-vl:4b”，最后出现 “扫描汇总”，就说明一切正常。用完可删除 `D:\试跑`、`D:\试跑计划.csv` 和 `D:\ExanteZZH\venv`（试跑用的环境，不会打进离线包）。

<a id="sec-10"></a>
### 步骤 7：检查离线包

`D:\offline_ai` 里应该有：

```
OllamaSetup.exe
python-3.14.x-amd64.exe
install_offline.ps1
ollama_models\      ← 模型（约 13GB）
wheels\             ← Python 依赖包（约 20MB）
file_organizer\     ← 整理工具
docs\               ← 本手册等文档
```

<a id="sec-11"></a>
### 步骤 8：拷到 U 盘

把整个 `D:\offline_ai` 文件夹复制到 U 盘（约 14GB，USB 3.0 约 5–15 分钟）。

<a id="sec-12"></a>
## 第二部分：在断网电脑上安装

<a id="sec-13"></a>
### 步骤 9：把离线包复制到本机

把 U 盘里的 `offline_ai` 文件夹复制到 `D:\offline_ai`（在本机上运行比直接在 U 盘上快）。

<a id="sec-14"></a>
### 步骤 10：安装 Ollama

1. 双击 `D:\offline_ai\OllamaSetup.exe` → **Install**。
   - 如果出现 “Windows 已保护你的电脑”：点 **更多信息** → **仍要运行**。
2. 装好后右下角出现羊驼图标。

<a id="sec-15"></a>
### 步骤 11：安装 Python

双击 `D:\offline_ai\python-3.14.x-amd64.exe`，和步骤 3 一样：**勾选 “Add python.exe to PATH”** → Install Now → Close。
新开 PowerShell 输入 `python --version` 确认。

<a id="sec-16"></a>
### 步骤 12：运行安装脚本

1. 进入 `D:\offline_ai`，地址栏输入 `powershell` 回车。
2. 输入：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install_offline.ps1 -Dest D:\AI
   ```
3. 脚本会依次：
   - `[1/4]` 复制模型到 `D:\AI\ollama_models`（几分钟）
   - `[2/4]` 复制整理工具到 `D:\AI\file_organizer`，文档到 `D:\AI\docs`，依赖包到 `D:\AI\wheels`（留在本机，以后重建环境不再需要 U 盘）
   - `[3/4]` 设置 Ollama：模型位置、只允许本机访问、一次只装一个模型（16GB 内存需要）
   - `[4/4]` 创建工具专用的 Python 环境 `D:\AI\venv`，并从 `D:\AI\wheels` 离线安装依赖包（系统 Python 不装任何包），最后显示 `Packages OK`
4. 看到 `Done.` 即完成。

**可选：用防火墙禁止 Ollama 联网（双保险）**
开始菜单搜索 “PowerShell” → 右键 **以管理员身份运行**，然后输入：
```powershell
cd D:\offline_ai
powershell -ExecutionPolicy Bypass -File .\install_offline.ps1 -Dest D:\AI -BlockFirewall
```
（请用你平时登录的账号来运行，否则设置会落到别的账号上。）

<a id="sec-17"></a>
### 步骤 13：重启 Ollama（必须）

1. 右键右下角羊驼图标 → **Quit Ollama**。
2. 开始菜单 → 搜索 **Ollama** → 打开。

（安装脚本设置的选项要重启 Ollama 才生效。）

<a id="sec-18"></a>
### 步骤 14：验证安装

**新开**一个 PowerShell 窗口，逐条检查：

1. 模型是否都在：
   ```powershell
   ollama list
   ```
   应看到 `llama3.1:8b`、`qwen3-vl:4b`（和 `qwen3:8b`）。

2. 英德文模型能否回答：
   ```powershell
   ollama run llama3.1:8b "Fasse in einem Satz zusammen: Das ist ein Test."
   ```
   得到一句德文回答即可。输入 `/bye` 退出。

3. 照片模型能否看图（先放一张照片到 `D:\test.jpg`）：
   ```powershell
   ollama run qwen3-vl:4b "用一句话描述这张照片 D:\test.jpg"
   ```
   得到一句中文描述即可。输入 `/bye` 退出。

4. 工具的 Python 环境是否正常：
   ```powershell
   D:\AI\venv\Scripts\python.exe -c "import pypdf, docx, openpyxl, pptx, PIL, pillow_heif; print('依赖正常')"
   ```

四项都通过，安装完成。

<a id="sec-19"></a>
## 第三部分：第一次使用——小范围试点

先用少量文件试，确认分得准、流程熟悉，再正式整理。试点全程用“复制”模式，不碰原文件。

<a id="sec-20"></a>
### 步骤 15：准备试点文件

新建 `D:\试点`，**复制**（不是剪切）50–100 个有代表性的文件进去：中文文档、英文文档、德文文档、照片各若干，再放几个视频、压缩包。

<a id="sec-21"></a>
### 步骤 16：扫描

```powershell
cd D:\AI\file_organizer
.\organize.bat scan "D:\试点" --out D:\AI\计划_试点.csv
```

屏幕上会依次看到：

```
第 1 步：分流 80 个文件（不用模型）...
  合同.docx -> 中文文档/合同.docx
  video.mp4 -> 音视频/video.mp4
  ...
第 2 步：英文德文文档 30 个，模型 llama3.1:8b
  [1/30] Rechnung.pdf -> 英文德文文档/财务票据/2024-03-01_Rechnung Telekom März.pdf
  ...
第 2 步：照片 20 个，模型 qwen3-vl:4b
  [1/20] IMG_0012.jpg -> 照片/风景旅行/2023-08-15_海边日落.jpg
  ...
===== 扫描汇总 =====
目录中文件 80 个，计划表 80 行。
```

- 这一步**不会动任何文件**，只生成计划表。
- 中途想停：按 `Ctrl + C`，出现 “终止批处理操作吗(Y/N)?” 时输入 `Y` 回车。以后再运行同一条命令，会跳过已处理的文件接着跑。
- 最后一行 “目录中文件 X 个，计划表 X 行” 两个数应相等。

<a id="sec-22"></a>
### 步骤 17：用 Excel 检查计划表

1. 双击 `D:\AI\计划_试点.csv` 用 Excel（或 WPS）打开。
2. 各列含义：

   | 列 | 含义 | 能改吗 |
   |---|---|---|
   | action | `move` = 整理；`skip` = 不动 | 能 |
   | source | 原文件位置 | **不要改** |
   | language | 中文 / 英文 / 德文 / 照片 / 未知 | 参考 |
   | category | 要放进的文件夹，可多级，用 `/` 分隔，如 `英文德文文档/合同协议` | 能 |
   | new_name | 新文件名（中文文档保持原名） | 能 |
   | summary / tags | 中文摘要、关键词，帮你判断分得对不对 | 参考 |
   | confidence | 把握：高/中/低；“规则”表示按扩展名、字符或关键词确定 | 参考 |
   | note | 标“建议人工确认”的要重点看 | 参考 |
   | duplicate_of | 内容完全相同的另一个文件，这类默认 `skip` | 参考 |
   | sha256 | 文件指纹 | **不要改** |

3. 快速检查的方法：选中第一行 → **数据 → 筛选**，然后在 note 列筛选包含 “建议人工确认” 的行，先看这些。
4. 分错的直接改 category；不想动的把 action 改成 `skip`。
5. 保存：按 `Ctrl + S`，如果提示 “可能会丢失某些功能”，选 **是 / 保留当前格式**。用“另存为”时，类型选 **CSV UTF-8（逗号分隔）**。
6. **保存后关闭 Excel**，再进行下一步。

<a id="sec-23"></a>
### 步骤 18：预览

```powershell
.\organize.bat apply D:\AI\计划_试点.csv --target "D:\试点_结果" --dry-run
```

只在屏幕上列出 “原位置 -> 新位置”，不动文件。

<a id="sec-24"></a>
### 步骤 19：试点执行（复制模式）

```powershell
.\organize.bat apply D:\AI\计划_试点.csv --target "D:\试点_结果" --copy
```

结束时会显示对账：

```
===== 对账 =====
计划表 80 个 = 已复制 79 + 跳过 1 + 失败 0
归档清单：D:\试点_结果\_归档索引\归档清单_20261025_103000.csv
归档汇总表：D:\试点_结果\_归档索引\归档汇总_20261025_103000.xlsx
```

<a id="sec-25"></a>
### 步骤 20：检查结果

1. 打开 `D:\试点_结果`，看看文件夹结构：
   ```
   中文文档\
   英文德文文档\合同协议\  财务票据\  工作报告\ …
   照片\风景旅行\  证件卡片\  屏幕截图\ …
   音视频\  压缩包\  未识别语言\
   _归档索引\
   ```
2. 打开 `_归档索引\归档汇总_….xlsx`：
   - **汇总**页：每个大类、每个细分类别各多少个文件、多大
   - **明细**页：每个文件的新旧位置、语言、摘要
   - **未归档**页：跳过或失败的文件和原因
3. 核对文件是否完好：
   ```powershell
   .\organize.bat verify "D:\试点_结果"
   ```
   显示 “全部完好” 即可。

<a id="sec-26"></a>
### 步骤 21：评估并调整

1. 在 Excel 里数一下分错了多少个，算出大致准确率。
2. 某类总是分错，按第六部分调整 `config.json`（加关键词、改类别说明、换模型）。
3. 调整后重新试点：**先删掉旧的 `D:\AI\计划_试点.csv` 和 `D:\试点_结果`**（否则扫描会跳过已处理过的文件），再从步骤 16 开始。
4. 满意后，删除 `D:\试点_结果` 即可（它是复制出来的，原文件没动）。

<a id="sec-27"></a>
## 第四部分：正式整理

<a id="sec-28"></a>
### 步骤 22：备份

整理前把要整理的文件夹完整复制一份到移动硬盘。工具有多重保护，但重要资料备份永远是第一道保险。

<a id="sec-29"></a>
### 步骤 23：扫描

```powershell
cd D:\AI\file_organizer
.\organize.bat scan "D:\待整理" --out D:\AI\计划_20261025.csv
```

- 文件多时可以挂机过夜。先设置不休眠：**设置 → 系统 → 电源 → 屏幕和睡眠 → 接通电源时“从不”**，并接上电源。
- 关掉浏览器等占内存的软件。
- 中断了就再运行同一条命令，会接着跑。
- 照片很多又只想按年份分：命令末尾加 `--photo-model none`，照片部分会快很多。

<a id="sec-30"></a>
### 步骤 24：检查计划表

和步骤 17 一样。重点看：
- note 列 “建议人工确认” 的行
- category 是 `未识别语言` 的行（多为扫描件，可以手动改成正确的文件夹）
- duplicate_of 有内容的行（重复文件，默认不动，留在原处）

改完保存并关闭 Excel。

<a id="sec-31"></a>
### 步骤 25：预览，然后执行

```powershell
.\organize.bat apply D:\AI\计划_20261025.csv --target "D:\已整理" --dry-run
.\organize.bat apply D:\AI\计划_20261025.csv --target "D:\已整理"
```

- 第二条是**移动**。同一磁盘内是直接改名，瞬间完成；跨磁盘会先复制、核对指纹一致后才删原文件。
- 磁盘空间够的话，可以在末尾加 `--copy` 改为复制，原文件完全不动，最保险（需要双倍空间）。
- 看对账结果：计划表总数 = 已移动 + 跳过 + 失败。失败的文件仍在原位置，原因见汇总表的 “未归档” 页。

### 步骤 26：核对

```powershell

```

显示 “全部完好” 即完成。以后把 `D:\已整理` 拷到别的硬盘后，也可以对新位置再核对一次。

### 步骤 27：收尾

（文件名以实际生成的为准，在计划表同一文件夹里。）文件会回到原位置。

<a id="sec-36"></a>
## 第六部分：调整设置（config.json）

位置：`D:\AI\file_organizer\config.json`。

**修改方法**：右键 → 打开方式 → **记事本**。改之前先复制一份备份。保存时编码保持 **UTF-8**。

**格式规则**：所有引号必须是英文双引号 `"`；每项之间用英文逗号 `,` 隔开，但每组最后一项后面**不要**加逗号。改错了运行时会提示第几行有误。

<a id="sec-37"></a>
### 常用修改

**1. 中文文档也让 Qwen 细分**（合同、发票、报告……）

找到：
```json
    "zh": {
      "folder": "中文文档",
      "model": "",
```
把 `"model": ""` 改成 `"model": "qwen3:8b"`。
（只想临时试一次：扫描命令末尾加 `--zh-model qwen3:8b`。）

**2. 照片只按拍摄年份分，不用看图模型**

把 `"photo"` 里的 `"model": "qwen3-vl:4b"` 改成 `"model": ""`。
（临时：扫描命令末尾加 `--photo-model none`。）

**3. 增加或修改类别**

在 `"en_de"` 的 `"categories"` 里，每行是 `"文件夹名": "英文/德文说明"`。比如加一个“保险”类：
```json
        "保险文件": "insurance policies, claims / Versicherungen, Policen",
```
说明写得越清楚，模型分得越准。照片的类别在 `"photo"` 的 `"categories"` 里，说明可以留空 `""`。

**4. 文件名关键词规则**（优先于模型）

```json
  "keyword_rules": {
    "财务票据": ["发票", "报销", "invoice", "rechnung"],
```
文件名里含这些词（不分大小写）就直接归入该类。可以加你常见的词，如供应商名、项目名。注意：类别名要和 categories 里的一致。

**5. 只看文件名判断中文**

把 `"language_detect": "content"` 改成 `"language_detect": "filename"`。默认的 `content` 会看文件开头的文字，更准。

**6. 其他**

| 项 | 作用 | 建议 |
|---|---|---|
| `max_chars` | 每个文件读取多少字给模型 | 1000（快）～3000（准），默认 2000 |
| `photo_max_side` | 照片缩小到多少像素给模型 | 768（快）～1024（默认） |
| `name_template` | 命名格式 | 默认 `{date}_{title}`，可改为 `{title}_{date}` |
| `skip_dirs` | 不扫描的文件夹名 | 可加入不想动的文件夹 |

改完后用试点文件夹再跑一遍确认效果（记得先删旧的计划表）。

## 第七部分：Python 环境维护

整理工具使用自己的 Python 环境，和系统 Python 完全分开：

| 位置 | 内容 |
|---|---|
| 系统 Python（`C:\Users\用户名\AppData\Local\Programs\Python\Python314\`） | 只用来创建环境，不装任何包 |
| `D:\AI\venv\` | 工具专用环境，所有依赖包都在这里 |
| `D:\AI\wheels\` | 依赖包的离线安装文件，用来重建环境 |
| `D:\AI\file_organizer\requirements.txt` | 依赖包清单，版本已固定 |
| `D:\AI\file_organizer\organize.bat` | 运行入口，自动使用 `D:\AI\venv`，不需要“激活”环境 |
| `D:\AI\file_organizer\setup_venv.bat` | 创建或重建环境 |

<a id="sec-39"></a>
### 重建环境（环境坏了、报缺少模块时）

```powershell
cd D:\AI\file_organizer
.\setup_venv.bat
```

它会删掉旧的 `D:\AI\venv`，重新创建，并从 `D:\AI\wheels` 离线安装依赖包，约 1 分钟。不影响设置、计划表和已整理的文件。

<a id="sec-40"></a>
### 查看环境里装了什么

```powershell
D:\AI\venv\Scripts\python.exe -m pip list
```

<a id="sec-41"></a>
### 升级 Python 或依赖包

1. 在联网电脑上用新版本重新打包（例如改用 Python 3.15：先装 3.15，再加 `-PyVersion 3.15` 运行打包脚本）。
2. 在断网电脑上安装新版 Python，再运行一次 `install_offline.ps1`，它会自动用新的依赖包重建 `D:\AI\venv`。你改过的 `config.json` 会保留。

<a id="sec-42"></a>
### 卸载

- 只卸载工具环境：删除 `D:\AI\venv` 文件夹即可。
- 全部卸载：删除 `D:\AI` 文件夹；在 “设置 → 应用” 中卸载 Ollama 和 Python。整理好的文件（如 `D:\已整理`）不受影响。

## 第八部分：常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `python 不是内部或外部命令` | 安装 Python 时没勾 “Add python.exe to PATH” | 重新运行 Python 安装程序 → Modify → 勾选 “Add Python to environment variables”；或卸载重装并勾选 |
| 输入 python 弹出应用商店 | Windows 自带的应用别名 | 设置 → 应用 → 高级应用设置 → 应用执行别名，关掉 python.exe、python3.exe |
| `连不上 Ollama` | Ollama 没运行 | 开始菜单打开 Ollama；看右下角是否有羊驼图标 |
| `本机缺少模型：…` | 模型没导入或路径不对 | 运行 `ollama list`；确认做过步骤 13（重启 Ollama）；模型文件应在 `D:\AI\ollama_models` |
| `ollama list` 是空的 | Ollama 没读到新的模型位置 | 退出 Ollama 后重开；仍不行就**注销或重启电脑**一次 |
| 安装脚本 `[4/4]` 失败，或 `setup_venv.bat` 显示 `Setup failed` | 断网电脑的 Python 版本和打包时不同 | 两边都用 3.14；或在联网电脑用 `-PyVersion 3.13` 等重新打包 |
| `Python environment not found` | 工具环境 `D:\AI\venv` 还没建或被删了 | 运行 `.\setup_venv.bat` |
| 提示 `No module named …` | 工具环境损坏 | 运行 `.\setup_venv.bat` 重建 |
| 输入 `organize.bat` 提示找不到 | 不在工具文件夹里，或前面少了 `.\` | 先 `cd D:\AI\file_organizer`，命令写成 `.\organize.bat …` |
| 运行很慢、电脑卡 | 内存不够或照片太多 | 关闭其他软件；照片用 `--photo-model none`；`max_chars` 调小 |
| 计划表 Excel 打开乱码 | 少见 | Excel：数据 → 从文本/CSV 导入，编码选 UTF-8 |
| 执行时 “源文件不存在” | 扫描后文件被移动或改名；或计划表另存时路径中的特殊字符变成了 “?” | 重新扫描；保存计划表时选 “CSV UTF-8” |
| 执行时提示权限不足 / 文件被占用 | 文件正被其他程序打开 | 关闭相关程序，重新执行同一计划表（已整理的会提示源文件不存在并跳过） |
| `配置文件格式有误：第 N 行` | config.json 改错了 | 按提示行号检查引号、逗号；或恢复备份 |
| 很多文档进了 “未识别语言” | 扫描件 PDF、老格式 .doc/.xls 读不到文字 | 手动处理；或用 WPS/Office 批量另存为 .docx/.xlsx 后再扫描 |
| HEIC 照片打不开 | 依赖包没装好 | 运行步骤 14 第 4 条检查；不正常就运行 `.\setup_venv.bat` |
| 想换别的模型 | — | 在联网电脑 `ollama pull 模型名`，按步骤 5、9、12 的方式把 `ollama_models` 重新拷过去 |
